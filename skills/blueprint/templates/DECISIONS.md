# Decisions

Every structural choice made with the operator, in the order taken. Documents cite these as
`(D-nnn)`. A decision is never deleted; a reversed one gets a new record that says
"supersedes D-nnn", and the old one gets "superseded by D-mmm". A decision the sources already
took is not copied here — it is cited (`S-01 §D14`). A *Revisit?* question about one is answered by
a record here that says `keeps S-01 §D14` or `supersedes S-01 §D14`, so it is not raised again.

*Decided by* names who made the choice — the operator, or the operator on someone's request (a
customer's feedback, a colleague's review) — so that a later reader knows whom to ask.
