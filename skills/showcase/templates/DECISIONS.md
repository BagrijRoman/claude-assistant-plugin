# Decisions

Every choice made for the showcase, with the alternatives beside it and the reason. The Decisions
page of the site is written from this file (`tools/genDecisions.mjs`); edit here, then regenerate.
A choice from the blueprint cites its `D-` id. SC-001 to SC-008 are the choices every showcase
makes, filled when each is taken; any other choice is a new row from SC-009, in the order taken.
